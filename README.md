# HyperTech Website

Static marketing and support site for HyperTech and Solar Explorer.

## GitHub Pages

1. Create a new GitHub repository for this folder.
2. Push these files to the repository default branch.
3. Enable GitHub Pages for the branch.
4. Add the custom domain `hyperte.ch` in the Pages settings.
5. Configure DNS for `hyperte.ch` using GitHub Pages' current DNS instructions.

## Key URLs

- Marketing: https://hyperte.ch/
- Solar Explorer support: https://hyperte.ch/support.html
- Solar Explorer privacy: https://hyperte.ch/privacy.html
